Parámetros usados en esta HU: PAR-GEN-01 (zona horaria de la plataforma), PAR-GEN-02 (reintentos de envío de correo), PAR-RES-06 (anticipación del correo de confirmación de asistencia), PAR-RES-07 (hora mínima de inicio que exige confirmación), PAR-RES-08 (plazo para confirmar la asistencia), PAR-RES-11 (frecuencia de la tarea programada).
- **Restricciones de diseño:** Tarea programada en segundo plano. Los enlaces del correo deben identificar la reserva de forma segura (por ejemplo, con un token firmado) y llevar a la aplicación.
- Solo se envía a reservas CONFIRMADAS cuya confirmación de asistencia esté PENDIENTE.
- El correo incluye los datos de la reserva, un enlace para confirmar la asistencia (HU27), un enlace para cancelar la reserva (HU24) y la hora límite para responder.

## Criterios de aceptación

| Código | Escenario |
|---|---|
| CA1 | Dado que un jugador tiene una reserva CONFIRMADA con confirmación de asistencia PENDIENTE, cuando falten 5 horas para su inicio, entonces recibe un correo (COR-RES-06) con los datos de la reserva, el enlace para confirmar la asistencia, el enlace para cancelar y la hora límite para responder (3 horas antes del inicio). |
| CA2 | Dado que un jugador tiene una reserva con confirmación de asistencia NO_REQUERIDA, cuando falten 5 horas para su inicio, entonces no se le envía el correo de confirmación. |
| CA3 | Dado que una reserva fue cancelada antes de que falten 5 horas para su inicio, cuando se ejecute la tarea programada, entonces no se envía el correo de confirmación. |
| CA4 | Dado que ya se envió el correo de confirmación de una reserva, cuando la tarea programada se ejecute de nuevo, entonces no se vuelve a enviar el correo para esa reserva (queda registrada la fecha de envío). Si la tarea se ejecuta cuando ya faltan 3 horas o menos y el correo no se había enviado (por ejemplo, porque la aplicación estuvo apagada), no se envía y la confirmación de asistencia pasa a NO_REQUERIDA: la reserva se mantiene (D34). |
| CA5 | Dado que un jugador recibió el correo de confirmación, cuando use el enlace para cancelar, entonces se le lleva a la cancelación de la reserva y se aplican las reglas de HU24. |
