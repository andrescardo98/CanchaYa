- **Para:** volver a ofrecer ese horario a los jugadores

> Como Administrador de cancha o encargado de sede, necesito eliminar un bloqueo de una cancha, para volver a ofrecer ese horario a los jugadores

## Criterios de aceptación

| Código | Escenario |
|---|---|
| CA1 | Dado que un administrador de cancha o un encargado de sede quiere liberar un horario bloqueado de su escenario, cuando ejecute la acción definida para eliminar el bloqueo y acepte el mensaje de confirmación (CNF-BLO-01), entonces se elimina el bloqueo, el horario vuelve a ofrecerse a los jugadores y se muestra el mensaje de éxito (EXI-BLO-02). |
| CA2 | Dado que un administrador de cancha quiere eliminar un bloqueo, cuando cancele el mensaje de confirmación (CNF-BLO-01), entonces el bloqueo se conserva. |
| CA3 | Dado que un administrador de cancha quiere eliminar un bloqueo, cuando el bloqueo no exista, entonces no se elimina nada y se muestra el mensaje de error (ERR-BLO-09), indicando que no existe un bloqueo con ese identificador. |
| CA4 | Dado que se recibe una solicitud para eliminar un bloqueo, cuando el usuario autenticado no sea el administrador propietario ni un encargado asignado al escenario, entonces no se elimina y se muestra el mensaje de error (ERR-BLO-10), indicando que no tiene permiso para eliminar este bloqueo. |
