- **Catálogo de parámetros:** Catálogo de parámetros - CanchaYa.xlsx (1.1.9.5 Artefactos apoyo). Parámetros usados en esta HU: PAR-GEN-01 (zona horaria de la plataforma), PAR-RES-08 (plazo para confirmar la asistencia).
- **Restricciones de diseño:** El enlace del correo identifica la reserva de forma segura; si el jugador no tiene sesión iniciada, se le pide iniciarla y luego se completa la confirmación.
- Confirmar la asistencia no cambia el estado de la reserva (sigue CONFIRMADA): solo cambia la confirmación de asistencia a CONFIRMADA.
- Si el jugador decide no asistir, debe cancelar la reserva (HU24).

## Criterios de aceptación

| Código | Escenario |
|---|---|
| CA1 | Dado que un jugador recibió el correo de confirmación de una reserva, cuando use el enlace para confirmar mientras falten más de 3 horas para el inicio, entonces la confirmación de asistencia queda CONFIRMADA, la reserva se conserva y se muestra el mensaje de éxito (EXI-RES-03). |
| CA2 | Dado que un jugador usa el enlace para confirmar la asistencia, cuando no tenga sesión iniciada, entonces se le pide iniciar sesión y, al hacerlo, se completa la confirmación. |
| CA3 | Dado que un jugador usa el enlace para confirmar la asistencia, cuando falten 3 horas o menos para el inicio, entonces no se confirma y se muestra el mensaje de error (ERR-RES-27), indicando que el plazo para confirmar la asistencia ya venció. |
| CA4 | Dado que un jugador usa el enlace para confirmar la asistencia, cuando la asistencia ya esté confirmada o no se requiera, entonces no se hace ningún cambio y se muestra el mensaje (ERR-RES-26), indicando que la asistencia ya fue confirmada o no requiere confirmación. |
| CA5 | Dado que un jugador usa el enlace para confirmar la asistencia, cuando la reserva ya no esté CONFIRMADA (por ejemplo, porque se canceló), entonces no se confirma y se muestra el mensaje de error (ERR-RES-14), indicando que la reserva no existe o ya no está confirmada. |
| CA6 | Dado que se recibe una solicitud para confirmar la asistencia, cuando el usuario autenticado no sea el jugador de la reserva, entonces no se confirma y se muestra el mensaje de error (ERR-RES-25), indicando que no tiene permiso para confirmar la asistencia de esta reserva. |
