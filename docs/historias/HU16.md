## Tarjeta

- **Como:** Administrador del sistema
- **Necesito:** modificar el código, el nombre o la capacidad de jugadores de un tipo de cancha
- **Para:** corregir o actualizar el catálogo de modalidades

> Como Administrador del sistema, necesito modificar el código, el nombre o la capacidad de jugadores de un tipo de cancha, para corregir o actualizar el catálogo de modalidades


## Conversación historia

- **Requisito de información:** Modelo de dominio enriquecido, hoja TipoCancha: atributos y responsabilidad modificar (políticas 1, 3, 5 y 6).
- **Prototipo:** Prototipo «Tipos de cancha»: Prototipos/Celular y Prototipos/Computador, archivo «10 Tipos de cancha.png» (1.1.9.5 Artefactos apoyo).
- **Catálogo de mensajes:** Catálogo de mensajes - CanchaYa.xlsx (1.1.9.5 Artefactos apoyo), hoja «Mensajes». Códigos usados en esta HU: EXI-TCA-02, ERR-GEN-01, ERR-GEN-02, ERR-GEN-03, ERR-GEN-04, ERR-TCA-01, ERR-TCA-03, ERR-TCA-05, ERR-TCA-06.
- **Catálogo de parámetros:** Catálogo de parámetros - CanchaYa.xlsx (1.1.9.5 Artefactos apoyo). Parámetros usados en esta HU: PAR-TCA-01 (capacidad de jugadores de un tipo de cancha).
- **Restricciones de diseño:** Solo el rol ADMINISTRADOR_SISTEMA; se valida en el servidor.
- El cambio se refleja en todas las canchas que usan ese tipo, porque la cancha guarda la referencia al tipo y no una copia de sus datos.
- Al validar si otro tipo ya tiene el código se excluye el tipo que se está modificando.

## Criterios de aceptación

| Código | Escenario |
|---|---|
| CA1 | Dado que el administrador del sistema quiere modificar un tipo de cancha, cuando cambie el código, el nombre o la capacidad de jugadores de forma correcta y ejecute la acción definida para guardar, entonces se persisten los cambios, se actualiza la lista del catálogo y se muestra el mensaje de éxito (EXI-TCA-02), indicando que el tipo de cancha se modificó de forma satisfactoria. |
| CA2 | Dado que el administrador del sistema quiere modificar un tipo de cancha, cuando ingrese alguno de los datos de forma incorrecta, incumpliendo alguna de las reglas especificadas en el requisito de información, y ejecute la acción definida para guardar, entonces no se persiste la información y se muestran los mensajes de error respectivos al usuario (Problemas de obligatoriedad: ERR-GEN-01, Problemas de formato: ERR-GEN-02, Problemas de longitud: ERR-GEN-03, Problemas de rango: ERR-GEN-04), indicando cuál fue el problema presentado y cómo puede remediarlo. |
| CA3 | Dado que se recibe una solicitud para modificar un tipo de cancha, cuando el usuario autenticado no tenga el rol Administrador del sistema, entonces no se persisten los cambios y se muestra el mensaje de error (ERR-TCA-01), indicando que solo el administrador del sistema puede gestionar los tipos de cancha. |
| CA4 | Dado que el administrador del sistema quiere modificar un tipo de cancha, cuando el tipo no exista y ejecute la acción definida para guardar, entonces no se persisten los cambios y se muestra el mensaje de error (ERR-TCA-05), indicando que no existe un tipo de cancha con ese identificador. |
| CA5 | Dado que el administrador del sistema quiere modificar un tipo de cancha, cuando le asigne un código que ya tiene otro tipo y ejecute la acción definida para guardar, entonces no se persisten los cambios y se muestra el mensaje de error (ERR-TCA-06), indicando que ya existe otro tipo de cancha con ese código. |
| CA6 | Dado que el administrador del sistema quiere modificar un tipo de cancha, cuando ingrese una capacidad de jugadores menor que 2 o mayor que 22 y ejecute la acción definida para guardar, entonces no se persisten los cambios y se muestra el mensaje de error (ERR-TCA-03), indicando que la capacidad de jugadores debe estar entre 2 y 22. |
