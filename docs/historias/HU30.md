# HU30-Bloquear un horario

## Tarjeta

- **Como:** Administrador de cancha o encargado de sede
- **Necesito:** bloquear un horario de una cancha por mantenimiento, torneo, uso propio o reserva presencial
- **Para:** que los jugadores no puedan reservar ese horario

> Como Administrador de cancha o encargado de sede, necesito bloquear un horario de una cancha por mantenimiento, torneo, uso propio o reserva presencial, para que los jugadores no puedan reservar ese horario


## Conversación historia

- **Requisito de información:** Modelo de dominio enriquecido, hoja Bloqueo: atributos y responsabilidad crear y validarSolapamiento (políticas 1 a 8, 12 y 13).
- **Prototipo:** Prototipo «Agenda del escenario: nuevo bloqueo»: Prototipos/Celular y Prototipos/Computador, archivo «18 Agenda del escenario - nuevo bloqueo.png» (1.1.9.5 Artefactos apoyo).
- **Catálogo de mensajes:** Catálogo de mensajes - CanchaYa.xlsx (1.1.9.5 Artefactos apoyo), hoja «Mensajes». Códigos usados en esta HU: EXI-BLO-01, ERR-BLO-01, ERR-BLO-02, ERR-BLO-03, ERR-BLO-04, ERR-BLO-05, ERR-BLO-06, ERR-GEN-01, ERR-GEN-02, ERR-GEN-03, ERR-GEN-04, ERR-BLO-12.
- **Catálogo de parámetros:** Catálogo de parámetros - CanchaYa.xlsx (1.1.9.5 Artefactos apoyo). Parámetros usados en esta HU: PAR-HOR-02 (granularidad de horarios y bloqueos). Un bloqueo no está sujeto a los límites de RN-08, RN-09 ni RN-10.
- **Restricciones de diseño:** El solapamiento con otros bloqueos y con reservas confirmadas se valida en el servidor.
- Deben tenerse en cuenta los campos descritos en el requisito de información que no deben ser visibles por el usuario: id y creadoPor (se toma del usuario autenticado).
- El tipo de bloqueo se elige entre Mantenimiento, Torneo, Uso propio y Reserva presencial; el motivo es opcional. Cada bloqueo cubre un rango de horas de un solo día; los bloqueos de varios días o recurrentes son trabajo futuro.
- Si en el horario hay una reserva confirmada, primero el administrador propietario debe cancelarla por fuerza mayor (HU32) y luego crear el bloqueo; el encargado de sede no puede cancelarla.

## Criterios de aceptación

| Código | Escenario |
|---|---|
| CA1 | Dado que un administrador de cancha o un encargado de sede quiere bloquear un horario, cuando seleccione la cancha, la fecha, la hora de inicio, la hora de fin y el tipo de bloqueo de forma correcta, ejecute la acción definida para bloquear y el horario esté libre, entonces se persiste el bloqueo con el usuario que lo creó, el horario aparece bloqueado en la agenda, deja de ofrecerse a los jugadores y se muestra el mensaje de éxito (EXI-BLO-01). |
| CA2 | Dado que un administrador de cancha o un encargado de sede quiere bloquear un horario, cuando ingrese alguno de los datos de forma incorrecta, incumpliendo alguna de las reglas especificadas en el requisito de información, y ejecute la acción definida para bloquear, entonces no se persiste la información y se muestran los mensajes de error respectivos al usuario (Problemas de obligatoriedad: ERR-GEN-01, Problemas de formato: ERR-GEN-02, Problemas de longitud: ERR-GEN-03, Problemas de rango: ERR-GEN-04), indicando cuál fue el problema presentado y cómo puede remediarlo. |
| CA3 | Dado que un administrador de cancha o un encargado de sede quiere bloquear un horario, cuando la cancha no exista, entonces no se persiste el bloqueo y se muestra el mensaje de error (ERR-BLO-01), indicando que no existe la cancha que se quiere bloquear. |
| CA4 | Dado que se recibe una solicitud para bloquear un horario, cuando el usuario autenticado no sea el administrador propietario ni un encargado asignado al escenario de la cancha, entonces no se persiste el bloqueo y se muestra el mensaje de error (ERR-BLO-02), indicando que no tiene permiso para bloquear horarios en este escenario. |
| CA5 | Dado que se recibe una solicitud para bloquear un horario, cuando no se envíe el tipo de bloqueo o no sea uno de los valores permitidos, entonces no se persiste el bloqueo y se muestra el mensaje de error (ERR-BLO-03), indicando que debe seleccionar un tipo de bloqueo válido. |
| CA6 | Dado que un administrador de cancha o un encargado de sede quiere bloquear un horario, cuando la hora de fin sea igual o anterior a la hora de inicio, entonces no se persiste el bloqueo y se muestra el mensaje de error (ERR-BLO-04), indicando que la hora de fin debe ser mayor que la hora de inicio. |
| CA7 | Dado que un administrador de cancha o un encargado de sede quiere bloquear un horario, cuando se cruce con otro bloqueo de la misma cancha, entonces no se persiste el bloqueo y se muestra el mensaje de error (ERR-BLO-05), indicando que ya existe un bloqueo en ese horario. |
| CA8 | Dado que un administrador de cancha o un encargado de sede quiere bloquear un horario, cuando se cruce con una reserva confirmada de la cancha, entonces no se persiste el bloqueo y se muestra el mensaje de error (ERR-BLO-06), indicando que hay una reserva confirmada en ese horario y cuál es la reserva en conflicto. |
| CA9 | Dado que un administrador de cancha o un encargado de sede quiere bloquear un horario, cuando ingrese una hora de inicio o de fin que no sea en punto, entonces no se persiste el bloqueo y se muestra el mensaje de error (ERR-BLO-12), indicando que los bloqueos se definen en horas en punto. |
| CA10 | Dado que un administrador de cancha o un encargado de sede quiere bloquear una cancha, cuando diligencie el formulario, entonces solo puede indicar una fecha y un rango de horas de ese día; para bloquear varios días debe crear un bloqueo por cada día. |
