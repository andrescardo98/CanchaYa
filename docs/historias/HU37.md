## Conversación historia

- **Requisito de información:** Modelo de dominio enriquecido, hoja Reseña: atributos y responsabilidad publicar (políticas 1 a 5, 7 y 8).
- **Prototipo:** Prototipo «Publicar reseña»: Prototipos/Celular y Prototipos/Computador, archivo «21 Publicar reseña.png» (1.1.9.5 Artefactos apoyo).
- **Catálogo de mensajes:** Catálogo de mensajes - CanchaYa.xlsx (1.1.9.5 Artefactos apoyo), hoja «Mensajes». Códigos usados en esta HU: EXI-RSE-01, ERR-GEN-01, ERR-GEN-03, ERR-RSE-01, ERR-RSE-02, ERR-RSE-03, ERR-RSE-04, ERR-RSE-05.
- **Catálogo de parámetros:** Catálogo de parámetros - CanchaYa.xlsx (1.1.9.5 Artefactos apoyo). Parámetros usados en esta HU: PAR-RSE-01 (rango de la calificación), PAR-RSE-02 (longitud máxima del comentario de una reseña).
- **Restricciones de diseño:** La calificación promedio no se almacena: se calcula al consultar, así que la nueva reseña se refleja de inmediato.
- La opción para calificar aparece en Mis reservas solo en las reservas que ya finalizaron y no están canceladas ni marcadas como inasistencia.
- Se permite una sola reseña por reserva; el comentario es opcional. Una vez publicada, la reseña no se puede editar ni eliminar; la moderación de comentarios es trabajo futuro.
- Deben tenerse en cuenta los campos descritos en el requisito de información que no deben ser visibles por el usuario: id y fechaCreacion.

## Criterios de aceptación

| Código | Escenario |
|---|---|
| CA1 | Dado que un jugador quiere opinar sobre un escenario en el que jugó, cuando seleccione una reserva finalizada, elija una calificación de 1 a 5, escriba opcionalmente un comentario y ejecute la acción definida para publicar, entonces se persiste la reseña, la calificación promedio del escenario la incluye desde la siguiente consulta, la opción de calificar desaparece para esa reserva y se muestra el mensaje de éxito (EXI-RSE-01). |
| CA2 | Dado que un jugador quiere publicar una reseña, cuando no elija la calificación o el comentario supere los 500 caracteres, entonces no se persiste la reseña y se muestran los mensajes de error respectivos (Problemas de obligatoriedad: ERR-GEN-01, Problemas de longitud: ERR-GEN-03). |
| CA3 | Dado que se recibe una reseña, cuando la calificación no sea un número entero entre 1 y 5, entonces no se persiste y se muestra el mensaje de error (ERR-RSE-05), indicando que la calificación debe ser un número de 1 a 5. |
| CA4 | Dado que se recibe una reseña, cuando la reserva aún no haya finalizado, esté CANCELADA o esté marcada como NO_ASISTIO, entonces no se persiste y se muestra el mensaje de error (ERR-RSE-03), indicando que solo puede reseñar reservas que ya jugó. |
| CA5 | Dado que se recibe una reseña, cuando ya exista una reseña para esa reserva, entonces no se persiste y se muestra el mensaje de error (ERR-RSE-04), indicando que ya publicó una reseña para esta reserva. |
| CA6 | Dado que se recibe una reseña, cuando la reserva no exista, entonces no se persiste y se muestra el mensaje de error (ERR-RSE-01), indicando que no existe la reserva que se quiere reseñar. |
| CA7 | Dado que se recibe una reseña, cuando el usuario autenticado no sea el jugador de la reserva, entonces no se persiste y se muestra el mensaje de error (ERR-RSE-02), indicando que solo puede reseñar sus propias reservas. |
| CA8 | Dado que un jugador ya publicó una reseña, cuando consulte sus reservas o las reseñas del escenario, entonces no se le ofrece ninguna opción para editarla ni eliminarla. |
