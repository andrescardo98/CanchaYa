## Tarjeta

- **Como:** Jugador
- **Necesito:** cancelar una reserva confirmada con más de 3 horas de antelación
- **Para:** liberar la cancha cuando ya no puedo asistir

> Como Jugador, necesito cancelar una reserva confirmada con más de 3 horas de antelación, para liberar la cancha cuando ya no puedo asistir


## Conversación historia

- **Requisito de información:** Modelo de dominio enriquecido, hoja Reserva: atributos y responsabilidad cancelar (políticas 14, 15, 16, 19, 20 y 21).
- **Prototipo:** Prototipo «Mis reservas»: Prototipos/Celular y Prototipos/Computador, archivo «15 Mis reservas.png» (1.1.9.5 Artefactos apoyo).
- **Catálogo de mensajes:** Catálogo de mensajes - CanchaYa.xlsx (1.1.9.5 Artefactos apoyo), hoja «Mensajes». Códigos usados en esta HU: EXI-RES-02, CNF-RES-01, ERR-RES-14, ERR-RES-15, ERR-RES-16.
- **Catálogo de parámetros:** Catálogo de parámetros - CanchaYa.xlsx (1.1.9.5 Artefactos apoyo). Parámetros usados en esta HU: PAR-GEN-01 (zona horaria de la plataforma), PAR-RES-05 (antelación mínima para cancelar).
- **Restricciones de diseño:** La regla de las 3 horas se valida en el servidor con su propia hora, no con la del dispositivo.
- Antes de cancelar se pide confirmación al jugador.
- Al cancelar se registran la fecha de cancelación y el origen JUGADOR, y las franjas de la reserva vuelven a quedar libres.

## Criterios de aceptación

| Código | Escenario |
|---|---|
| CA1 | Dado que un jugador quiere cancelar una reserva confirmada, cuando falten más de 3 horas para su inicio, ejecute la acción definida para cancelar y acepte el mensaje de confirmación (CNF-RES-01), entonces la reserva queda CANCELADA con origen JUGADOR y su fecha de cancelación, la franja vuelve a estar disponible, se envían los correos de cancelación (HU25) y se muestra el mensaje de éxito (EXI-RES-02). |
| CA2 | Dado que un jugador quiere cancelar una reserva, cuando cancele el mensaje de confirmación (CNF-RES-01), entonces la reserva sigue CONFIRMADA. |
| CA3 | Dado que se recibe una solicitud del jugador para cancelar una reserva, cuando falten 3 horas o menos para su inicio, entonces no se cancela y se muestra el mensaje de error (ERR-RES-16), indicando que ya no es posible cancelar porque faltan 3 horas o menos para el partido. |
| CA4 | Dado que se recibe una solicitud para cancelar una reserva, cuando la reserva no exista o no esté CONFIRMADA, entonces no se cancela y se muestra el mensaje de error (ERR-RES-14), indicando que la reserva no existe o ya no está confirmada. |
| CA5 | Dado que se recibe una solicitud para cancelar una reserva, cuando el usuario autenticado no sea el jugador que la hizo, entonces no se cancela y se muestra el mensaje de error (ERR-RES-15), indicando que no tiene permiso para cancelar esta reserva. |
