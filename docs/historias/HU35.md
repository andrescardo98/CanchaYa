## Conversación historia

- **Catálogo de parámetros:** No aplican parámetros de negocio.
- **Restricciones de diseño:** Solo el administrador propietario consulta los encargados de sus escenarios; se valida en el servidor.
- Para cada encargado se muestran su nombre, su correo electrónico y la fecha de asignación.
- Desde esta lista se accede a asignar (HU34) y retirar (HU36) encargados.

## Criterios de aceptación

| Código | Escenario |
|---|---|
| CA1 | Dado que un administrador de cancha quiere saber quién atiende sus sedes, cuando ingrese a los encargados de uno de sus escenarios, entonces se listan los usuarios asignados con su nombre, su correo electrónico y la fecha de asignación. |
| CA2 | Dado que un administrador de cancha consulta los encargados de un escenario, cuando no haya encargados asignados, entonces se muestra el mensaje (INF-ENC-01), indicando que el escenario no tiene encargados y cómo asignar uno. |
| CA3 | Dado que se recibe una consulta de los encargados de un escenario, cuando el usuario autenticado no sea su administrador propietario, entonces no se muestra la información y se muestra el mensaje de error (ERR-ENC-02), indicando que no tiene permiso para gestionar los encargados de este escenario. |
