## Tarjeta

- **Como:** Administrador del sistema
- **Necesito:** eliminar un tipo de cancha que ninguna cancha utilice
- **Para:** mantener el catálogo libre de modalidades que no se usan

> Como Administrador del sistema, necesito eliminar un tipo de cancha que ninguna cancha utilice, para mantener el catálogo libre de modalidades que no se usan


## Conversación historia

- **Requisito de información:** Modelo de dominio enriquecido, hoja TipoCancha: atributos y responsabilidad eliminar (políticas 1, 5 y 7).
- **Prototipo:** Prototipo «Tipos de cancha»: Prototipos/Celular y Prototipos/Computador, archivo «10 Tipos de cancha.png» (1.1.9.5 Artefactos apoyo).
- **Catálogo de mensajes:** Catálogo de mensajes - CanchaYa.xlsx (1.1.9.5 Artefactos apoyo), hoja «Mensajes». Códigos usados en esta HU: EXI-TCA-03, CNF-TCA-01, ERR-TCA-01, ERR-TCA-05, ERR-TCA-07.
- **Catálogo de parámetros:** No aplican parámetros de negocio.
- **Restricciones de diseño:** Eliminación definitiva; se valida en el servidor que ninguna cancha use el tipo.
- Antes de eliminar se pide confirmación al usuario.
- Solo se puede eliminar un tipo que ninguna cancha utilice; si está en uso, primero se deben cambiar de tipo esas canchas.

## Criterios de aceptación

| Código | Escenario |
|---|---|
| CA1 | Dado que el administrador del sistema quiere eliminar un tipo de cancha que ninguna cancha utiliza, cuando ejecute la acción definida para eliminar y acepte el mensaje de confirmación (CNF-TCA-01), entonces se elimina el tipo, se actualiza la lista del catálogo y se muestra el mensaje de éxito (EXI-TCA-03). |
| CA2 | Dado que el administrador del sistema quiere eliminar un tipo de cancha, cuando cancele el mensaje de confirmación (CNF-TCA-01), entonces no se elimina el tipo y la lista queda igual. |
| CA3 | Dado que el administrador del sistema quiere eliminar un tipo de cancha, cuando al menos una cancha esté clasificada con ese tipo, entonces no se elimina y se muestra el mensaje de error (ERR-TCA-07), indicando que el tipo está asignado a una o más canchas y no se puede eliminar. |
| CA4 | Dado que el administrador del sistema quiere eliminar un tipo de cancha, cuando el tipo no exista, entonces no se elimina nada y se muestra el mensaje de error (ERR-TCA-05), indicando que no existe un tipo de cancha con ese identificador. |
| CA5 | Dado que se recibe una solicitud para eliminar un tipo de cancha, cuando el usuario autenticado no tenga el rol Administrador del sistema, entonces no se elimina y se muestra el mensaje de error (ERR-TCA-01), indicando que solo el administrador del sistema puede gestionar los tipos de cancha. |
