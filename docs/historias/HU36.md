- **Para:** quitarle de inmediato el acceso cuando deja de atenderla

> Como Administrador de cancha, necesito retirar a un encargado de una sede, para quitarle de inmediato el acceso cuando deja de atenderla


## Conversación historia

- **Requisito de información:** Modelo de dominio enriquecido, hoja EncargadoEscenario: atributos y responsabilidad retirar (políticas 2, 6, 7 y 8).
- **Prototipo:** Prototipo «Encargados de sede»: Prototipos/Celular y Prototipos/Computador, archivo «20 Encargados de sede.png» (1.1.9.5 Artefactos apoyo).

- **Catálogo de parámetros:** No aplican parámetros de negocio.
- **Restricciones de diseño:** Como los permisos se validan en cada solicitud contra las asignaciones vigentes, el retiro tiene efecto inmediato aunque el encargado tenga una sesión abierta.
- Antes de retirar se pide confirmación al usuario.
- Los bloqueos que creó el encargado se conservan.

## Criterios de aceptación

| Código | Escenario |
|---|---|
| CA1 | Dado que un administrador de cancha quiere quitarle el acceso a un encargado, cuando ejecute la acción definida para retirarlo y acepte el mensaje de confirmación (CNF-ENC-01), entonces se elimina la asignación, se actualiza la lista de encargados y se muestra el mensaje de éxito (EXI-ENC-02). |
| CA2 | Dado que un administrador de cancha quiere retirar a un encargado, cuando cancele el mensaje de confirmación (CNF-ENC-01), entonces la asignación se conserva. |
| CA3 | Dado que un encargado fue retirado de un escenario, cuando intente consultar su agenda, crear un bloqueo o marcar una inasistencia en él, entonces la acción no se ejecuta y se muestra el mensaje de error de permisos correspondiente. |
| CA4 | Dado que un encargado retirado había creado bloqueos en el escenario, cuando se consulte la agenda, entonces esos bloqueos se conservan. |
| CA5 | Dado que un administrador de cancha quiere retirar a un encargado, cuando la asignación no exista, entonces no se elimina nada y se muestra el mensaje de error (ERR-ENC-06), indicando que no existe la asignación del encargado. |
| CA6 | Dado que se recibe una solicitud para retirar un encargado, cuando el usuario autenticado no sea el administrador propietario del escenario, entonces no se elimina la asignación y se muestra el mensaje de error (ERR-ENC-02), indicando que no tiene permiso para gestionar los encargados de este escenario. |
