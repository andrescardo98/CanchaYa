## Tarjeta

- **Como:** Administrador del sistema
- **Necesito:** registrar una nueva modalidad de fútbol con su código, nombre y capacidad de jugadores
- **Para:** que los administradores de cancha puedan clasificar sus canchas en modalidades que no estaban en el catálogo

> Como Administrador del sistema, necesito registrar una nueva modalidad de fútbol con su código, nombre y capacidad de jugadores, para que los administradores de cancha puedan clasificar sus canchas en modalidades que no estaban en el catálogo

## Criterios de aceptación

| Código | Escenario |
|---|---|
| CA1 | Dado que el administrador del sistema quiere registrar un nuevo tipo de cancha, cuando ingrese el código, el nombre y la capacidad de jugadores de forma correcta, ejecute la acción definida para registrar y no exista otro tipo con el mismo código, entonces se persiste el tipo de cancha, se actualiza la lista del catálogo, se limpia el formulario y se muestra el mensaje de éxito (EXI-TCA-01), indicando que el tipo de cancha se registró de forma satisfactoria. |
| CA2 | Dado que el administrador del sistema quiere registrar un nuevo tipo de cancha, cuando ingrese alguno de los datos de forma incorrecta, incumpliendo alguna de las reglas especificadas en el requisito de información, y ejecute la acción definida para registrar, entonces no se persiste la información y se muestran los mensajes de error respectivos al usuario (Problemas de obligatoriedad: ERR-GEN-01, Problemas de formato: ERR-GEN-02, Problemas de longitud: ERR-GEN-03, Problemas de rango: ERR-GEN-04), indicando cuál fue el problema presentado y cómo puede remediarlo. |
| CA3 | Dado que se recibe una solicitud para registrar un tipo de cancha, cuando el usuario autenticado no tenga el rol Administrador del sistema, entonces no se persiste la información y se muestra el mensaje de error (ERR-TCA-01), indicando que solo el administrador del sistema puede gestionar los tipos de cancha. |
| CA4 | Dado que el administrador del sistema quiere registrar un tipo de cancha, cuando ingrese todos los datos de forma correcta, ejecute la acción definida para registrar y ya exista un tipo con el mismo código, entonces no se persiste la información y se muestra el mensaje de error (ERR-TCA-02), indicando que ya existe un tipo de cancha con ese código. |
| CA5 | Dado que el administrador del sistema quiere registrar un tipo de cancha, cuando ingrese una capacidad de jugadores menor que 2 o mayor que 22 y ejecute la acción definida para registrar, entonces no se persiste la información y se muestra el mensaje de error (ERR-TCA-03), indicando que la capacidad de jugadores debe estar entre 2 y 22. |
| CA6 | Dado que el administrador del sistema quiere registrar un nuevo tipo de cancha, cuando haya ingresado información en un campo determinado del formulario de forma correcta y pierda el foco de este, entonces se aplican las validaciones necesarias para asegurar la integridad del dato según las reglas especificadas en el requisito de información, y no se muestra ningún mensaje dado que la validación es exitosa. |
| CA7 | Dado que el administrador del sistema quiere registrar un nuevo tipo de cancha, cuando haya ingresado información en un campo determinado del formulario de forma incorrecta, incumpliendo alguna de las reglas especificadas en el requisito de información, y pierda el foco de este, entonces se aplica la validación respectiva y se muestra junto al campo el mensaje de error correspondiente (Problemas de obligatoriedad: ERR-GEN-01, Problemas de formato: ERR-GEN-02, Problemas de longitud: ERR-GEN-03, Problemas de rango: ERR-GEN-04), indicando cuál fue el problema presentado y cómo puede remediarlo. |
| CA8 | Dado que el administrador del sistema quiere registrar un tipo de cancha, cuando haya ingresado el código, pierda el foco del campo y ya exista un tipo con ese código, entonces se muestra junto al campo el mensaje de error (ERR-TCA-02), indicando que ya existe un tipo de cancha con ese código. |
