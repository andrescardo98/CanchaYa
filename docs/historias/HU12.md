## Tarjeta

- **Como:** Administrador de cancha
- **Necesito:** eliminar un horario de atención
- **Para:** dejar de ofrecer franjas en días u horas en que ya no atiendo

> Como Administrador de cancha, necesito eliminar un horario de atención, para dejar de ofrecer franjas en días u horas en que ya no atiendo


## Conversación historia

- **Requisito de información:** Modelo de dominio enriquecido, hoja HorarioRecurrente: atributos y responsabilidad eliminar (políticas 2, 6, 8 y 15).
- **Prototipo:** Prototipo «Horarios de atención»: Prototipos/Celular y Prototipos/Computador, archivo «08 Horarios de atención.png» (1.1.9.5 Artefactos apoyo).
- **Catálogo de mensajes:** Catálogo de mensajes - CanchaYa.xlsx (1.1.9.5 Artefactos apoyo), hoja «Mensajes». Códigos usados en esta HU: EXI-HOR-03, CNF-HOR-01, CNF-HOR-02, ERR-HOR-02, ERR-HOR-06, ERR-HOR-15.
- **Catálogo de parámetros:** No aplican parámetros de negocio.
- **Restricciones de diseño:** Eliminación definitiva del registro; las franjas dejan de calcularse para ese día y rango.
- Antes de eliminar se pide confirmación al usuario.
- Si el escenario se queda sin horarios, sus canchas dejan de aparecer en la búsqueda (RN-04); el mensaje de confirmación lo advierte.

## Criterios de aceptación

| Código | Escenario |
|---|---|
| CA1 | Dado que un administrador de cancha quiere eliminar un horario de atención, cuando ejecute la acción definida para eliminar y acepte el mensaje de confirmación (CNF-HOR-01), entonces se elimina el horario, se actualiza la lista de horarios, se dejan de ofrecer las franjas de ese día y rango y se muestra el mensaje de éxito (EXI-HOR-03). |
| CA2 | Dado que un administrador de cancha quiere eliminar un horario de atención, cuando ejecute la acción definida para eliminar y cancele el mensaje de confirmación (CNF-HOR-01), entonces no se elimina el horario y la lista queda igual. |
| CA3 | Dado que un administrador de cancha quiere eliminar el único horario que le queda a su escenario, cuando ejecute la acción definida para eliminar, entonces el mensaje de confirmación (CNF-HOR-02) advierte que las canchas del escenario dejarán de aparecer en la búsqueda hasta que defina un nuevo horario. |
| CA4 | Dado que un administrador de cancha quiere eliminar un horario, cuando el horario no exista, entonces no se elimina nada y se muestra el mensaje de error (ERR-HOR-06), indicando que no existe un horario con ese identificador. |
| CA5 | Dado que se recibe una solicitud para eliminar un horario, cuando el usuario autenticado no sea el administrador propietario del escenario (incluido un encargado de sede), entonces no se elimina el horario y se muestra el mensaje de error (ERR-HOR-02), indicando que no tiene permiso para gestionar los horarios de este escenario. |
| CA6 | Dado que un administrador de cancha quiere eliminar un horario, cuando haya reservas confirmadas futuras en ese día de la semana y rango de horas, entonces no se elimina el horario y se muestra el mensaje de error (ERR-HOR-15), indicando que hay reservas confirmadas futuras dentro de ese horario. |
