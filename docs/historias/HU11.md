## Tarjeta

- **Como:** Administrador de cancha
- **Necesito:** cambiar el día o las horas de un horario de atención
- **Para:** ajustar la disponibilidad cuando cambian mis horarios

> Como Administrador de cancha, necesito cambiar el día o las horas de un horario de atención, para ajustar la disponibilidad cuando cambian mis horarios


## Conversación historia

- **Requisito de información:** Modelo de dominio enriquecido, hoja HorarioRecurrente: atributos y responsabilidad modificar (políticas 2, 3, 6, 7, 13 y 14).
- **Prototipo:** Prototipo «Horarios de atención»: Prototipos/Celular y Prototipos/Computador, archivo «08 Horarios de atención.png» (1.1.9.5 Artefactos apoyo).
- **Catálogo de mensajes:** Catálogo de mensajes - CanchaYa.xlsx (1.1.9.5 Artefactos apoyo), hoja «Mensajes». Códigos usados en esta HU: EXI-HOR-02, ERR-GEN-01, ERR-GEN-02, ERR-GEN-03, ERR-GEN-04, ERR-HOR-02, ERR-HOR-03, ERR-HOR-06, ERR-HOR-07, ERR-HOR-13.
- **Catálogo de parámetros:** Catálogo de parámetros - CanchaYa.xlsx (1.1.9.5 Artefactos apoyo). Parámetros usados en esta HU: PAR-HOR-01 (duración de la franja), PAR-HOR-02 (granularidad de horarios y bloqueos).
- **Restricciones de diseño:** Las franjas se recalculan en cada consulta, por lo que el cambio se refleja de inmediato en la disponibilidad.
- Se pueden cambiar el día de la semana, la hora de inicio y la hora de fin. El escenario del horario no se modifica.
- El cambio aplica hacia adelante: las reservas confirmadas ya registradas se respetan aunque queden por fuera del nuevo horario (RN-17).

## Criterios de aceptación

| Código | Escenario |
|---|---|
| CA1 | Dado que un administrador de cancha quiere modificar un horario de atención de su escenario, cuando cambie el día o las horas de forma correcta, ejecute la acción definida para guardar y el horario no se cruce con otro del mismo día, entonces se persisten los cambios, la disponibilidad de las canchas se calcula con el nuevo horario y se muestra el mensaje de éxito (EXI-HOR-02), indicando que el horario se modificó de forma satisfactoria. |
| CA2 | Dado que un administrador de cancha quiere modificar un horario de atención, cuando ingrese alguno de los datos de forma incorrecta, incumpliendo alguna de las reglas especificadas en el requisito de información, y ejecute la acción definida para guardar, entonces no se persiste la información y se muestran los mensajes de error respectivos al usuario (Problemas de obligatoriedad: ERR-GEN-01, Problemas de formato: ERR-GEN-02, Problemas de longitud: ERR-GEN-03, Problemas de rango: ERR-GEN-04), indicando cuál fue el problema presentado y cómo puede remediarlo. |
| CA3 | Dado que un administrador de cancha quiere modificar un horario, cuando el horario no exista y ejecute la acción definida para guardar, entonces no se persisten los cambios y se muestra el mensaje de error (ERR-HOR-06), indicando que no existe un horario con ese identificador. |
| CA4 | Dado que se recibe una solicitud para modificar un horario, cuando el usuario autenticado no sea el administrador propietario del escenario (incluido un encargado de sede), entonces no se persisten los cambios y se muestra el mensaje de error (ERR-HOR-02), indicando que no tiene permiso para gestionar los horarios de este escenario. |
| CA5 | Dado que un administrador de cancha quiere modificar un horario, cuando ingrese una hora de fin igual o anterior a la hora de inicio y ejecute la acción definida para guardar, entonces no se persisten los cambios y se muestra el mensaje de error (ERR-HOR-03), indicando que la hora de fin debe ser mayor que la hora de inicio. |
| CA6 | Dado que un administrador de cancha quiere modificar un horario, cuando el nuevo rango se cruce con otro horario del mismo día (distinto al que se modifica) y ejecute la acción definida para guardar, entonces no se persisten los cambios y se muestra el mensaje de error (ERR-HOR-07), indicando que el horario se cruza con otro ya definido para ese día. |
| CA7 | Dado que un administrador de cancha quiere modificar un horario, cuando ingrese una hora de inicio o de fin que no sea en punto y ejecute la acción definida para guardar, entonces no se persisten los cambios y se muestra el mensaje de error (ERR-HOR-13), indicando que los horarios se definen en horas en punto. |
| CA8 | Dado que un administrador de cancha quiere modificar un horario, cuando existan reservas confirmadas que queden por fuera del nuevo rango y ejecute la acción definida para guardar, entonces se persisten los cambios, esas reservas se conservan y la disponibilidad se calcula con el nuevo horario. |
